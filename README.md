# G Neeraj Flutter Portfolio

This is the Flutter implementation of the portfolio shown in the reference screenshots.

## Pages
1. Home Page
2. About Me Page

## Run
Create a Flutter project (or copy these files into an existing Flutter project), then run:

```bash
flutter pub get
flutter run
```

For a browser:
```bash
flutter run -d chrome
```

Main source: `lib/main.dart`
